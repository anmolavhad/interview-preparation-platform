# Interview Preparation Platform

A MERN stack web application for preparing technical interviews through subject-wise and mock MCQ tests.

## Features

- User Authentication (JWT)
- Subject-wise Tests
- Mock Tests
- Dashboard Analytics
- Score & Accuracy Tracking
- Test History

## Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt
